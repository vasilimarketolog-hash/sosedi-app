# Правила разработки проекта «Соседи.Онлайн» (sosedi-app)

## ⛔ КРИТИЧЕСКОЕ ПРАВИЛО: ЗАПРЕТ НА САМОВОЛЬНЫЙ ДЕПЛОЙ НА VERCEL
1. **Никогда не деплоить на Vercel самостоятельно.**
   - Запрещено выполнять команды `vercel`, `vercel --prod`, `npx vercel`, `vercel deploy` без прямого указания пользователя.
2. **Деплой производится только по явной команде пользователя.**
   - Когда пользователь напишет «деплой» / «задеплой на vercel» и укажет проект, только тогда выполнять команду.
3. **Локальный предпросмотр:**
   - Для проверки интерфейса использовать локальный сервер Vite (`npm run preview` или `npm run dev`) и предоставлять локальную ссылку.
